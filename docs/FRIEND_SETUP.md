# Shared box: setup for a friend

1. Unzip the folder anywhere.
2. Double-click `install-friend.bat` and wait for "Done".
3. In `C:\NMSpyMods\shared_box.toml`, set `player` to your name. Leave the token as sent.
4. **Before your first time:** start No Man's Sky normally, empty your **corvette cargo box 9**, then start with the .bat. (If you forget, the NMS.py window says refused — move everything out of corvette cargo box 9 and it connects by itself within a few seconds.)
5. Always start the game with `C:\NMSpyMods\start-nms-shared.bat`. If you play without it and touch corvette cargo box 9, the shared box will overwrite those changes next time.

The NMS.py window shows `connected` when it's working. `offline` means the box is locked until the connection comes back.
